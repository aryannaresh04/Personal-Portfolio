About Me

I'm Aryan Naresh, a Computer Science engineer specializing in Information Security at VIT Vellore, currently working as a Software Development Engineering Intern on the PLM team at Siemens Digital Industries Software. I build backend tools and services that are meant to run in production, not just demo well: real-time monitoring over Server-Sent Events, dependency-graph failure analysis, and hardening tools against penetration-test findings for air-gapped client deployments.

My projects range from ML-driven security systems to applied cryptography and blockchain. I built a SOC-style network intrusion detector that layers Random Forest and Isolation Forest models behind a FastAPI triage dashboard, a file-encryption tool pairing AES-256-GCM with Shamir's Secret Sharing for threshold key recovery, and an anti-counterfeiting system that verifies products against Ethereum smart contracts via QR codes. I also ship products end to end: React/Vite frontends, Node.js and FastAPI backends, ML microservices, and an LLM-powered resume agent that rewrites bullets and scrapes matching jobs.

Before Siemens, I was a Software Development Engineering Intern at CoreEL Technologies, building Qt/C++ flight instrument interfaces and a 3D aircraft simulator, plus a serial-port diagnostics tool with live data visualization.

I'm looking for SDE and security engineering roles where I can keep shipping systems that hold up under real-world constraints.

GitHub

Hybrid Encryption System

Python · AES-256-GCM · Shamir's Secret Sharing

File-encryption tool pairing AES-256-GCM authenticated encryption (256-bit key, per-file nonce) with Shamir's Secret Sharing for key protection. Splits the AES key into a 3-of-5 threshold share set distributed as QR codes, so any three of five shares reconstruct the key and no single share reveals it.

Blockchain-Based QR Code Product Authentication

Solidity · Truffle · Ganache · Web3.js · Node.js · MetaMask

Anti-counterfeiting system that registers products on an Ethereum blockchain and verifies authenticity by scanning QR codes against on-chain records. Built with Solidity smart contracts deployed via Truffle to a Ganache local chain, with a Web3.js frontend and MetaMask wallet integration for transaction signing.
