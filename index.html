About Me

I'm Aryan Naresh, a Computer Science engineer specializing in Information Security at VIT Vellore. From May to July 2026, I was a Software Development Engineering Intern on the PLM team at Siemens Digital Industries Software, where I built and shipped a monitoring tool to a live enterprise client. I build backend tools and services that are meant to run in production, not just demo well: real-time monitoring over Server-Sent Events, dependency-graph failure analysis, and hardening tools against penetration-test findings for air-gapped client deployments.

My projects range from systems programming and ML-driven security to applied cryptography and blockchain. I built cachedb, a Redis-compatible persistent key-value store in C++ with a write-ahead log and LSM-tree engine that matches real Redis on durable writes; a ticket booking platform that prevents double-booking with atomic seat holds; and I'm currently researching multilingual scam detection with explainable transformers across 23 languages. I also built a SOC-style network intrusion detector that layers Random Forest and Isolation Forest models behind a FastAPI triage dashboard, a file-encryption tool pairing AES-256-GCM with Shamir's Secret Sharing for threshold key recovery, and an anti-counterfeiting system that verifies products against Ethereum smart contracts via QR codes. Beyond that, I ship products end to end: React/Vite frontends, Node.js and FastAPI backends, ML microservices, and an LLM-powered resume agent that rewrites bullets and scrapes matching jobs.

Before Siemens, I was a Software Development Engineering Intern at CoreEL Technologies, building Qt/C++ flight instrument interfaces and a 3D aircraft simulator, plus a serial-port diagnostics tool with live data visualization.

I'm looking for SDE and security engineering roles where I can keep shipping systems that hold up under real-world constraints.
